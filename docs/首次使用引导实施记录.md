## 实际行为

- 初次使用三步引导已接入桌面与移动端，在创建 / 恢复工作空间之前显示。支持草稿恢复、跳过和设置页重开。
- `AppConfig::default()` 对全新设备允许截图；旧 JSON 缺字段仍按旧的禁止截图语义解析。配置损坏、读权限错误和未来引导版本均不能被默认配置覆盖。
- 引导提交先保存不可变操作意图，再执行系统设置；重复请求不重复执行已完成操作。部分失败保留原请求标识；结果未知先回读。UI 偏好写入单独 ACK，可恢复而不重放系统操作。
- Windows 调用返回值、Android 原生插件错误纳入保存结果；普通截图设置也在保存失败时尝试恢复原防护。
- iOS 显示后台预览保护与截屏提示的真实能力；Linux 禁用不支持的防截图选项；macOS 明示捕获限制效果取决于系统版本。
- 启动动效与解锁动画分开控制；启动动效 700ms，可跳过；初次引导前不播放强制动效，均遵循系统减少动态效果。
- 生物识别提醒只在工作空间已解锁且平台可用时出现；明确说明查看机密的联动，用户拒绝不会启用。真实生物识别授权仍由用户亲自完成。
- 手机安全区与输入法桥接提升至应用边界，使工作空间创建前也能接收原生 inset；操作区保留在可见范围，窄屏选择器改为整行。
