# 安卓真机调试（操作手册）

在 `dev` 上改完移动端后，按本文把 debug 包装到真机，并连上电脑上的 Vite。正式安装包走 `docs/发布新版本流程.md`，不要用本文出的包给用户。

**日常开发分支：** `dev`  
**调试包名：** `com.jeck.gitkeymaster.debug`  
**入口：** `com.jeck.gitkeymaster.MainActivity`  
**前端：** `http://127.0.0.1:5173`（经 `adb reverse` 转到电脑）

本机开发环境是 Hyper-V 虚拟机，**插 USB 进不了这台 Windows**。真机只能走无线调试。

---

## 推荐：一条脚本

在仓库根目录打开 PowerShell。先 `cd` 到仓库，再跑脚本。**命令写在最前面**，参数跟在后面，不要先打 `-Ip` 再打脚本。

```powershell
cd D:\coding_program\local-git-account-manage
powershell -ExecutionPolicy Bypass -File .\scripts\android-device-debug.ps1
```

脚本会先扫 `adb devices`：已在线就直接用，不问配对码。没有设备时才在终端问映射 IP/端口；重连失败才会要配对端口和配对码。

### 常用跑法

| 你想做什么 | 命令 |
|---|---|
| 改了 Rust / 第一次装到这台手机 | `.\scripts\android-device-debug.ps1`（完整：编库 → 打包 → 安装 → 打开） |
| 包已经打好，只想再推到手机 | `.\scripts\android-device-debug.ps1 -InstallOnly` |
| 手机上已经装着 debug 包，只改了前端 | `.\scripts\android-device-debug.ps1 -LaunchOnly` |
| 强制指定无线地址（一般不用） | 加上 `-Ip` `-ConnectPort`，必要时再加配对参数 |

也可以不套一层 `powershell -File`，在仓库根目录执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\android-device-debug.ps1 -InstallOnly
```

### 参数

| 参数 | 要不要填 | 作用 |
|---|---|---|
| 无参数 | 日常默认 | 自动找设备；需要时才询问。完整编包装机。 |
| `-LaunchOnly` | 可选 | **不编译、不打包、不安装**。只做：连设备、Vite、`adb reverse`、打开已装的 App。改 CSS/React 用这个。 |
| `-InstallOnly` | 可选 | **不编译、不打包**，把已经存在的 `app-arm64-debug.apk` **推到真机并启动**。上次完整跑过、APK 还在，就可以用。 |
| `-SkipNative` | 可选 | 和 `-LaunchOnly` 一样，只打开已装的 App，不再推包。 |
| `-SkipPair` | 可选 | 即使连不上也不走配对询问，直接失败。 |
| `-Ip` | 一般不用 | 手机无线调试 IP。不填则自动检测；没有设备时再问。 |
| `-ConnectPort` | 一般不用 | 映射/连接端口（无线调试**主界面**上的端口，不是配对端口）。 |
| `-PairPort` | 仅要配对时 | 「使用配对码配对」里的端口。脚本需要配对时才会问。 |
| `-PairCode` | 仅要配对时 | 6 位配对码。不要写在命令里也行，需要时终端会问。 |
| `-InstallTimeoutSec` | 很少改 | 推包超时秒数，默认 600。无线安装走 `adb push` + `pm install`，不再用容易卡住的 Streamed Install。 |

`-LaunchOnly` 和 `-InstallOnly` 不能一起用。

### 三种模式分别做什么

| 步骤 | 默认（完整） | `-InstallOnly` | `-LaunchOnly` / `-SkipNative` |
|---|---|---|---|
| 刷新环境 / 找设备 | 做 | 做 | 做 |
| 启动或复用 Vite | 做 | 做 | 做 |
| `adb reverse` 5173/5174 | 做 | 做 | 做 |
| 编译 ARM64 `.so` | 做 | 跳过 | 跳过 |
| Gradle 打包 | 做 | 跳过 | 跳过 |
| `adb install` 推包 | 做 | **做（用已有 APK）** | 跳过 |
| 打开 App | 做 | 做 | 做 |

`-InstallOnly` 用的文件：

```text
app\src-tauri\gen\android\app\build\outputs\apk\arm64\debug\app-arm64-debug.apk
```

没有这个文件，或大于 80MB（未瘦身的大包），脚本会拒绝推送，避免无线安装卡死。这时去掉 `-InstallOnly` 跑完整流程即可。

### 和「只改前端」的区别

- 只改了界面：用 `-LaunchOnly`，不用推包，热更新即可。
- 上次已经打好瘦身包，想换一台手机或重装：用 `-InstallOnly`。
- 改了 `app/src-tauri` 里的 Rust：必须跑**不带**这两个开关的完整脚本。

下面各节是脚本在做什么，以及脚本失败时的对照步骤。

---

## 0. 每次开终端先刷新环境

Cursor / 旧终端吃不到刚写进注册表的用户变量。新开 PowerShell 先跑：

```powershell
$env:Path = [Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [Environment]::GetEnvironmentVariable("Path","User")
foreach ($n in @(
  "JAVA_HOME","ANDROID_HOME","ANDROID_SDK_ROOT","NDK_HOME","ANDROID_NDK_HOME"
)) {
  $v = [Environment]::GetEnvironmentVariable($n, "User")
  if (-not $v) { $v = [Environment]::GetEnvironmentVariable($n, "Machine") }
  if ($v) { Set-Item "Env:$n" $v }
}
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
$hk = Get-ItemProperty HKCU:\Environment
$hk.PSObject.Properties |
  Where-Object { $_.Name -match '^(CC_|CXX_|AR_|CARGO_TARGET_).*ANDROID' } |
  ForEach-Object { Set-Item "Env:$($_.Name)" $_.Value }

Write-Host "JAVA_HOME=$env:JAVA_HOME"
Write-Host "ANDROID_HOME=$env:ANDROID_HOME"
Write-Host "NDK_HOME=$env:NDK_HOME"
adb version
```

| 变量 | 应对准 |
|---|---|
| `JAVA_HOME` | Temurin **17**（不要用 Android Studio 自带的 Java 25） |
| `ANDROID_HOME` | SDK 根，例如 `%LOCALAPPDATA%\Android\Sdk` |
| `NDK_HOME` / `ANDROID_NDK_HOME` | **具体版本目录**，例如 `...\ndk\29.0.14206865`，不要指到整个 `ndk` 文件夹 |

还要开 Windows **开发人员模式**（设置 → 隐私和安全性 → 开发人员），否则 `tauri` 在 `jniLibs` 里建符号链接会失败。

## 1. 手机打开无线调试

1. 手机和这台虚拟机要能互相访问（同一 Wi‑Fi，或都连 Tailscale）。
2. 手机：设置 → 开发者选项 → **无线调试** → 打开。
3. 点「使用配对码配对设备」，记下：
   - **配对** `IP:端口`（只用一次）
   - **配对码**（6 位）
4. 回到无线调试主界面，再看 **映射 / 连接** `IP:端口`（每次开关无线调试都会变）。

两个端口不是同一个。配对成功不等于已经连上。

---

## 2. 电脑连上真机

```powershell
adb pair <配对IP:配对端口> <配对码>
adb connect <映射IP:映射端口>
adb devices -l
```

`adb devices` 必须是 `device`，不能是 `offline` / `unauthorized`。

```text
<映射IP:端口>    device product:PJD110 model:PJD110 ...
```

常见翻车：

| 现象 | 处理 |
|---|---|
| `offline` | 手机解锁、无线调试保持开着；`adb disconnect <地址>` 后再 `adb connect`。端口变了就用主界面上的新端口。 |
| `failed to connect` | 映射端口已失效。重新看手机主界面，不要沿用上次的端口。 |
| `adb kill-server` 之后掉线 | 必须重新 `adb connect`。无线调试经不起杀 adb 服务。 |
| 配对过、只是掉线 | 不必再 pair，只 `adb connect` 新的映射端口。 |

后面命令里把设备写成变量：

```powershell
$serial = "<映射IP:映射端口>"   # 例如 100.109.28.90:39383
```

## 3. 启动前端（只开一份）

在仓库 `app` 目录：

```powershell
cd D:\coding_program\local-git-account-manage\app
npm run dev
```

Vite 监听 `127.0.0.1:5173`。桌面 `npm run tauri dev` 已经占着这个端口时，**不要再开一份**，直接复用。

然后把手机上的 5173 / 5174 转到电脑（热更新走 5174）：

```powershell
adb -s $serial reverse tcp:5173 tcp:5173
adb -s $serial reverse tcp:5174 tcp:5174
adb -s $serial reverse --list
```

这样 WebView 访问 `http://127.0.0.1:5173` 就是电脑上的 Vite，比走 Tailscale 快很多。

掉线重连后 **reverse 会丢**，必须再做一遍。

不要为了真机去设 `TAURI_DEV_HOST`（那会让 Vite 绑局域网 / Tailscale，首屏会很慢）。走 `adb reverse` 时保持默认 localhost。

---

## 4. 编 ARM64 native 库

官方 `npx tauri android dev <设备>` 在这台机器上经常认不出 `IP:端口` 这种无线序列号，会去开 Android Studio；编出来的 debug `.so` 大约 245MB，装包能到 500MB，无线传输会卡死。

按下面做。

```powershell
cd D:\coding_program\local-git-account-manage\app
npx tauri android android-studio-script --target aarch64
```

产物：

```text
app\src-tauri\target\aarch64-linux-android\debug\libapp_lib.so
```

剥掉调试符号（安装必须这一步）：

```powershell
$src = "D:\coding_program\local-git-account-manage\app\src-tauri\target\aarch64-linux-android\debug\libapp_lib.so"
$destDir = "D:\coding_program\local-git-account-manage\app\src-tauri\gen\android\app\src\main\jniLibs\arm64-v8a"
$dest = Join-Path $destDir "libapp_lib.so"
$strip = Join-Path $env:NDK_HOME "toolchains\llvm\prebuilt\windows-x86_64\bin\llvm-strip.exe"

New-Item -ItemType Directory -Force -Path $destDir | Out-Null
Remove-Item $dest -Force -ErrorAction SilentlyContinue
Copy-Item $src $dest -Force
& $strip --strip-unneeded $dest
(Get-Item $dest).Length   # 正常大约 20–30 MB，不要再是 200+ MB
```

这里必须是**拷贝后的实体文件**。若留下指向未剥离 `.so` 的符号链接，Gradle 会再打出 200MB+ 的包。

---

## 5. 打包并安装

```powershell
cd D:\coding_program\local-git-account-manage\app\src-tauri\gen\android
$apk = "app\build\outputs\apk\arm64\debug\app-arm64-debug.apk"

# 避免沿用上次那个几百 MB 的残包
Remove-Item $apk -Force -ErrorAction SilentlyContinue
Remove-Item "app\build\intermediates\incremental\packageArm64Debug" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item "app\build\intermediates\merged_native_libs\arm64Debug" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item "app\build\intermediates\stripped_native_libs\arm64Debug" -Recurse -Force -ErrorAction SilentlyContinue

.\gradlew.bat --no-daemon :app:packageArm64Debug -x rustBuildArm64Debug
(Get-Item $apk).Length   # 正常大约 40–50 MB
```

**一定要加** `-x rustBuildArm64Debug`。否则 Gradle 会再跑一遍 Tauri，把 `jniLibs` 里的瘦身库重新链回 245MB 的 debug `.so`。

确认设备仍是 `device` 后再装：

```powershell
adb -s $serial devices -l
adb -s $serial install -r -d $apk
```

`install` 没有进度条，45MB 走 Tailscale 大约一两分钟。超过五分钟还没 `Success`，停掉重连后再装，不要继续干等。

---

## 6. 启动应用

```powershell
adb -s $serial reverse tcp:5173 tcp:5173
adb -s $serial reverse tcp:5174 tcp:5174
adb -s $serial shell am force-stop com.jeck.gitkeymaster.debug
adb -s $serial shell am start -n com.jeck.gitkeymaster.debug/com.jeck.gitkeymaster.MainActivity
adb -s $serial shell pidof com.jeck.gitkeymaster.debug
```

有 pid 就说明进程起来了。界面从电脑 Vite 拉，改 React 保存后热更新；**改 Rust 必须从第 4 步重编、重装**。

只改前端、包已经是当前 debug 包时，杀进程再开即可，不必重装 APK。

## 7. 只改前端时的最短路径

设备已连、包已装过：

```powershell
# 终端 A
cd D:\coding_program\local-git-account-manage\app
npm run dev

# 终端 B
$serial = "<映射IP:映射端口>"

adb -s $serial shell am force-stop com.jeck.gitkeymaster.debug
adb -s $serial shell am start -n com.jeck.gitkeymaster.debug/com.jeck.gitkeymaster.MainActivity
```

## 8. 不要用的命令

```powershell
# 设备是位置参数，不是 --device
npx tauri android dev --device 100.x.x.x:xxxxx

# 无线序列号经常不被认成设备，会去开 Android Studio
npx tauri android dev 100.x.x.x:xxxxx

# 不跳过 rustBuild 时，会把瘦身库覆盖回 245MB
.\gradlew.bat :app:installArm64Debug
```

非要走官方 CLI 时，设备写在最后，并复用已经在跑的 Vite：

```powershell
npx tauri android dev --no-dev-server-wait --host 127.0.0.1 <映射IP:端口>
```

装包前仍要按第 4、5 步把 `.so` 剥符号，否则无线安装会卡死。

## 9. 验收与排错

| 检查 | 命令 / 预期 |
|---|---|
| 设备在线 | `adb devices` → `device` |
| 端口转发 | `adb reverse --list` 有 `tcp:5173`、`tcp:5174` |
| 进程 | `adb shell pidof com.jeck.gitkeymaster.debug` 有数字 |
| 保险库目录 | `/data/user/0/com.jeck.gitkeymaster.debug/`，不要在临时目录 |
| 首屏很慢 / 白屏 | 多半没做 `adb reverse`，或 Vite 绑了 Tailscale。先确认 reverse，再杀进程重开 |
| 装包一直无输出 | APK 是否又变成 200MB+；设备是否变成 `offline` |
| 改了 Rust 界面没变 | 只热更新了前端。重做第 4–6 步 |

看 Logcat：

```powershell
adb -s $serial logcat -s RustStdoutStderr:V AndroidRuntime:E
```

foreach ($n in @("JAVA_HOME","ANDROID_HOME","NDK_HOME","ANDROID_NDK_HOME")) {
  $v = [Environment]::GetEnvironmentVariable($n, "User")
  if ($v) { Set-Item "Env:$n" $v }
}
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME

adb connect $serial
adb -s $serial reverse tcp:5173 tcp:5173
adb -s $serial reverse tcp:5174 tcp:5174

# 另开一个终端：cd app; npm run dev
# 下面编库 + 瘦身 + 打包 + 安装

cd D:\coding_program\local-git-account-manage\app
npx tauri android android-studio-script --target aarch64

$src = "D:\coding_program\local-git-account-manage\app\src-tauri\target\aarch64-linux-android\debug\libapp_lib.so"
$dest = "D:\coding_program\local-git-account-manage\app\src-tauri\gen\android\app\src\main\jniLibs\arm64-v8a\libapp_lib.so"
$strip = Join-Path $env:NDK_HOME "toolchains\llvm\prebuilt\windows-x86_64\bin\llvm-strip.exe"
Remove-Item $dest -Force -ErrorAction SilentlyContinue

& $strip --strip-unneeded $dest

cd D:\coding_program\local-git-account-manage\app\src-tauri\gen\android
$apk = "app\build\outputs\apk\arm64\debug\app-arm64-debug.apk"
