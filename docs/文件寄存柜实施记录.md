## 实施约束

- 使用管理工作台方案；默认自己取用、24 小时、1 次，有限次数必须由兼容服务统一处理。
- 不以界面文案掩盖协议能力差异；旧服务上不可安全实施的操作明确阻止。
- 停止分享保留寄存对象；删除/到期/额度用尽的清理状态与访问状态分开。
- 不操作真实用户保险库、不使用现有云凭据部署、不改动独立运行的安装版。
- Worker 原同级源仓库未安装。已找回公开上游 `ice-juice/file-locker-worker`（基线 `896d7c53552ff7bd75b426bde4f9bf9925eb4e1b`），本次纳入可维护源文件与可复现内嵌构建，保留原始协议与依赖出处。
- 领取及上传结果不明时保留原操作 ID 查询；不自动创建重复写入或重复扣减。

## 已完成的功能与集成

- 管理工作台：连接状态、进行中/已结束/全部、搜索、刷新失败保留现有记录、文件详情、停止分享与独立删除、真实清理状态。
- 寄存：选文件只暂存，默认自用/24 小时/1 次；范围和整数校验；独立执行阶段；分享失败后保留原文件及分享意图，重新进入也可只补分享。
- 领取：区分本工作空间六码与完整外部分享链接；修改输入使查询失效；取消保存选择器不领取；先原子保存或保险库入库再 ACK；ACK 待确认仍显示已保存。
- 恢复：先持久化原操作，再发送变更；未知响应查询原 ID；已保存不重复下载；改存位置须显式操作并保留原领取名额，已有落盘见证时不再生成第二份。
- 数据一致性：领取入库在事务内重读合并；异步操作绑定工作空间会话代次；恢复上传绑定原 S3 endpoint/bucket/region/prefix；切换配置不能把原操作写向新目标。
- 分享/停止/迁移远端请求返回后，在事务内重读并只更新匹配的当前条目；并发同步新增/删除其他条目不会丢失；当前条目被删除或版本变化时拒绝覆盖，不复活墓碑。
- 服务：有限次数自用与分享使用同一原子名额机制，支持在途最后名额、原领取恢复、无破坏停止分享、独立清理和旧协议升级门禁。
- 迁移：主动确认后进行。已分享旧项以原服务权威剩余次数和到期时间为准；原服务数值可能与过时本地记录不同，但不增加服务已有名额。自用旧项仅依据本工作空间余量，并明确提示无法核对其他旧设备的历史取用。
- 与同工作区安全整改兼容：新分享片段为带完整性验证的 v2 格式，绑定服务、短码、明文大小与名称；旧链接要求发送方重新复制。前后端及网页领取按最终格式联合验收，未回退外部安全修改。

## 升级与使用边界

- 新有限次数规则和网页领取需要升级取件服务：使用“连接设置”中的服务部署/升级，再检测连接。两个部署路径均包含完整 `0002_locker_v2.sql`。
- 新签名分享链接需重新复制；旧未签名链接明确拒绝。旧寄存文件需主动点击“升级领取规则”，不得自动增加额度。
- 只配置云存储的基础自用模式仅允许明确不限次；没有取件服务时不承诺应用离线期间自动清理。到期记录需由在线客户端执行清理。
- 本次整合了同工作区另一会话已经落盘的安全修改，未回退或代替其完整安全审查。整体验证中修正/复验了 `.prev` 恢复和 Windows 恢复点同步写入兼容问题；构建记录以各次日志中的源码时点为准。
- Windows 本机构建使用既有 `windows-local-build.json` 关闭更新器签名产物生成，没有安装到用户设备、发布线上更新或覆盖已运行安装版。
