# 取件服务 v2 本地验证

维护源码：`services/file-locker-worker`，来自上游公开仓库的固定提交，详见该目录 `UPSTREAM.md`。不再依赖缺失的同级仓库。生产入口仅使用 v2 路由；历史 v1 实现与兼容测试作为参考保留，不可通过旧网络端点调用。

`npm run check`：35/35 通过，包括 17 个真实本地 workerd / D1 / R2 集成场景与 18 个 HMAC、帧及源码兼容场景。覆盖：

- 健康检查确认必要表和列、HMAC 拒绝、nonce 重放拒绝、旧写入接口返回 426。
- 登记幂等、参数冲突、原登记到期后的响应丢失恢复、带签名的桶绑定检查。
- 验码查询不扣次、持久化错误次数与锁定、私人寄存不通过六码公开枚举。
- 12 个并发请求争夺最后一个名额，仅一个成功；同操作并发重入仅扣一次。
- 停止分享保留对象和所有者访问；旧 alias 不复活；停止操作的旧重放不关闭之后的新分享。
- 已颁发的公开领取会话可继续，停止分享后不得创建新会话。
- 预留响应丢失后，停止分享或文件 TTL 到期仍可用原操作、版本和正确取件码恢复；其他操作、错误码和过恢复期请求仍拒绝。
- 实际重启本地 workerd 并轮换 HMAC secret 后，所有者和公开领取均能恢复原操作；新旧 token 同时有效但只能访问各自领取，D1 仅存哈希别名，不重复扣次。
- 未交付预留取消/超时仅退款一次；开始交付后失败、异常和超时不得释放名额。
- 实际 GKB1 / XChaCha20-Poly1305 加密内容经 HTTP 取回后解密与原文一致；限三次原会话恢复。
- `#v2` 签名片段与 Rust 固定向量一致，绑定服务地址、短码、完整明文大小和文件名；拒绝旧未签名片段及篡改信息。
- 整个有效分块截断、仅保留合法头部都无法通过完整明文大小校验；真实浏览器不触发下载及 ACK，对象保留供原操作恢复。
- 最后名额在 ACK 前保留 R2 对象；ACK 幂等且可重复查状态，完成后清理。
- 显式删除取消所有会话；清理故障显示 failed 并保留实际对象，重试后收敛。
- 旧分享迁移核对对象绑定、复制真实剩余次数，旧行的后续清理不能删除迁移后的对象。

`npm run test:browser`：真实 Chromium 页面与本地服务联测，实际下载文件哈希匹配；ACK 响应丢失只查询状态、不再次拉取内容；预留响应丢失、所有者停止分享并刷新后，输入验证码恢复同 operationId、只有一次扣减；密钥不发送给服务端、不写 sessionStorage；手机宽度没有横向溢出。机器结果见 `browser-service-check.json`。
