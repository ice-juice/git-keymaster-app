## 分工与集成边界

- core 独占 vault、biometric、session、commands/vault、commands/mod、sync/scheduler。
- sync 独占同步引擎/S3/备份、store事务和缓存、同步UI。
- private 独占账号/TOTP/文件/笔记命令、相关UI、PDF、剪贴板。
- root 负责更新、SSH、寄存柜完整性核验、共享IPC/注册/依赖/翻译、全量测试、本文。
- 分组详细记录：[core](core-progress.md)、[sync](sync-progress.md)、[private](private-progress.md)（由负责人逐项创建/更新）。

## 决策记录

1. 严格锁定撤销共享密钥会话，锁后不再解密同步；不以“后台便利”保留完整MK。
2. 恢复码采用prepare/commit：输入访问密码准备新码，确认保存后提交；取消和锁定不更改原码。
3. 跨文件保存统一使用 `store::transaction(vault, closure)`，加密redo journal先持久化，再安装；未恢复完不允许读取混代数据。
4. 补充加固项一起处理能够本地验证的部分；真机、实际云部署及泄露历史副本不可撤销的物理边界明确记录，不虚构验收。
