## 有意采用的安全行为与限制

- 同步 v2 包装需要所有参与设备升级。旧客户端无法解密新包装，失败关闭；不会假装双向兼容。
- 首次升级先拉取建立 ETag 基线；无 ETag/条件写支持的对象存储拒绝覆盖。CAS 防正常多设备竞争，不能单独抵御控制服务端故意忽略条件请求。
- 版本锚保存在本机受加密的 `data/sync-anchor-<scope>.enc`，scope 绑定 Endpoint/Bucket/Prefix，拉取与本地数据在同一事务提交，推送成功才推进。本机锚存在时拒绝整提交回放、同代分叉和协议降级；清空本机/重装/无锚新设备不具备此前历史，不能承诺跨重装抗回放。恶意服务端忽略 CAS 产生的分叉需人工处理。
- 物理垃圾回收暂缓，磁盘/云对象空间可能增长。未来需实现跨保留版本的独立、延迟回收作业；同步不承担破坏性回收。
- 离线备份包含寄存记录及取回 CK，**不包含远端寄存文件字节**，UI 明示；过期/已删除的远端文件不能因此复活。
- 备份导入/历史恢复之前建立 `backups/security-<UUID>` 完整加密工作空间。元数据复制，blob 硬链接（不支持时复制）；可用原凭据打开。现用库已损坏而不能验证完整检查点时，停止覆盖，需另行抢救。
- TOTP 同 ID 不同种子无法靠时钟安全决定，合并停止并提示先备份双端，删除墓碑不算冲突。账号冲突由内容组保留到密码历史。
- 真实 S3/R2 多端、断电耐久性、不同文件系统、移动真机未验证，仍需候选版本验收。
